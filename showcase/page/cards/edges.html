Edges and logo

The edges are rounded enough to print as smooth curves. The site’s wordmark and its book icon are both on the back; the chin is plain.

Front edges are mm rounds: nine 0.2 mm layers, so the curve reads smooth rather than stepped, and the first layer starts about a millimetre in from the side, which hides elephant’s foot. Back edges are mm, where your hand holds it. The parting line is square on both halves (until 2026-10-23 it had a 0.4 mm V from a chamfer on each). The key openings get mm chamfers, and the screen windowThe screen window gets a mm bevel.

The wordmark is the site repo’s logo, with the lettering converted to outlines. It is engraved in the back above the grip grooves (the chin is plain). The lid prints back face down, so it prints as gaps in the first layers; a cut narrower than a 0.4 mm nozzle can make there would close up, so the thinnest strokes are thickened just enough to stay open and the rest filtered out before the STL is written. At this size the icon’s strokes would be too fine, so the wordmark carries the lettering only.

The book icon is the site repo’s silkscreen-icon.svg, mirrored so it reads correctly from behind. The lid prints back face down, so the icon, like the wordmark, prints as gaps in the first layers.
